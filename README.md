# 🚀 Internship & Job Tracking Dashboard

## 📌 Project Description
This project is a Streamlit-based web application that helps manage internship and job opportunities. It uses PostgreSQL as the database and runs using Docker.

---

## 🧠 Features

- Add job/internship opportunities
- View all records
- Update job status
- Delete records
- Analytics dashboard (charts & KPIs)
- Deadline alerts (7 days)
- PostgreSQL database integration
- Docker containerization

---

## 🛠️ Tech Stack

- Python
- Streamlit
- PostgreSQL
- Docker
- Plotly
- Pandas

---

## 📂 Project Structure

app/ → Streamlit application  
database/ → SQL scripts  
queries.py → SQL queries  
docker-compose.yml → system setup
